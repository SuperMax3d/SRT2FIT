# SRT2FIT
DJI SRT file Converter to FIT file to be used in DJI Studio

Source code is in VB6. Included pre-compiled executable for Windows PC.

# Usage:
Fill the path toward the folder containing your SRT file. Adjust offset if there is time difference between the gps and the drone video time stamp.
Scale is not very useful.
Set the drone weight to estimate power draw
In DJI studio, add Dashboard and load the fit file corresponding. Activate the metric you want to display. (mostly Speed and Distance).
